# 🌦️ Weather Website

A responsive weather application built using HTML, CSS, and JavaScript. It allows users to search for locations and view real-time weather information using the free Open-Meteo API.

## ✨ Features

- Search weather by city or location name.
- Display current temperature in Celsius.
- Display relative humidity.
- Show weather conditions with corresponding icons.
- Support for Pulivendula and HSR Layout using custom coordinates.
- Display error messages for invalid city names.
- Fetch live weather data through API integration.
- Responsive user interface for different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Functionality and API integration.
- **Open-Meteo API** – Weather and geocoding data.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Enter a city or supported location in the search box.
5. Click the Search button to view weather information.

## 🌐 API Used

**Open-Meteo**

- Geocoding API: Finds location coordinates.
- Forecast API: Retrieves current temperature, humidity, and weather conditions.

Website: https://open-meteo.com/

No API key is required.
